A small Python program that writes a 111-character honest appliance error message — a vacuum whose bag is full of golden retriever — to /output/entry.txt. The line is fixed and deterministic: "Error: bag full. I have inhaled 2 kg of golden retriever. Biscuit is still shedding. I am full. Biscuit is not."

## Run it

```sh
python3 main.py
```
